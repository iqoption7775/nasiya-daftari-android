# Nasiya daftari — Android ilovasi

Nasiya daftari veb-ilovasi (`app/src/main/assets/www`) Android ichida ochiladi. SMS'lar telefonning o'z SIM kartasidan `SmsManager` orqali yuboriladi: bitta tugma bilan har bir mijozga o'z summasi yozilgan alohida SMS ketadi.

- APK har push'da GitHub Actions'da avtomatik yig'iladi (Actions → Android APK → Artifacts).
- `keystore/` dagi imzo kaliti ilovaning yangilanishlari eski versiya ustidan o'rnatilishi uchun kerak. Repozitoriyni **yopiq (private)** saqlang.
